# Task Manager App

## Overview
This project is a simple task management application built using React and Next.js. It allows users to create, organize, and manage their daily tasks in a clean and interactive interface.

## Features
- Add new tasks
- Mark tasks as complete or incomplete
- Delete tasks
- Filter tasks (All, Active, Completed)
- Clear all completed tasks
- View task counts (Total, Active, Completed)

## Technologies Used
- React (useState)
- Next.js
- Tailwind CSS

## How to Run
1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev

3. Open your browser and go to:
   http://localhost:3000
